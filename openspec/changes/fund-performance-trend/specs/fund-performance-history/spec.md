## ADDED Requirements

### Requirement: 多周期历史业绩走势查询
系统 SHALL 提供查询指定基金历史业绩走势的 API 接口，支持用户选择 7 种不同的时间跨度：近1月 (`1m`)、近3月 (`3m`)、近6月 (`6m`)、近1年 (`1y`)、近3年 (`3y`)、近5年 (`5y`) 和成立以来 (`all`)。

#### Scenario: 查询近1年历史业绩走势
- **WHEN** 客户端请求 `/api/fund/{code}/performance?range=1y`
- **THEN** 系统返回该基金近 1 年内的按日期排列的历史数据点列表，每个点包含日期、单位净值、累计净值、单日涨跌幅与区间累计收益率

#### Scenario: 缺少超长期限数据的次新基金查询
- **WHEN** 用户针对成立仅 1 年的次新基金请求 `range=3y` 或 `range=5y`
- **THEN** 系统正常返回该基金自成立以来的实际所有历史数据点，并在响应中标记实际数据跨度，不抛出异常

### Requirement: 历史业绩走势服务端缓存
系统 SHALL 对已收盘确认的历史净值数据实施服务端多级内存缓存，避免重复高频向上游数据源请求相同区间的历史数据。

#### Scenario: 相同基金与周期的多次并发访问
- **WHEN** 多个用户在短时间内连续请求同一只基金的 `range=6m` 历史业绩走势
- **THEN** 系统首次拉取后写入本地内存缓存，后续请求直接从本地缓存返回，不发起外部网络调用
