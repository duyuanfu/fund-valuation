## Context

当前系统聚焦于基金盘中实时估值与分时脉冲走势，但在单只基金详情页中，缺乏中长期历史维度的业绩走势呈现。用户在进行投资决策与持仓复盘时，既需要了解基金中长期的超额收益能力与回撤趋势，也迫切需要量化验证“本系统的盘中估值算法到底准不准”。

通过接入历史净值走势，并将本地沉淀的 `estimate_history` 盘中收盘前最终估算涨跌幅与基金官方公布的实际收盘净值涨跌幅进行对齐比对，形成“中长期业绩 + 估值准确性分析”的双重能力闭环。

## Goals / Non-Goals

**Goals:**
- 提供多时间范围的历史业绩走势图表，支持 7 档周期筛选：近1月 (`1m`)、近3月 (`3m`)、近6月 (`6m`)、近1年 (`1y`)、近3年 (`3y`)、近5年 (`5y`)、成立以来 (`all`)。
- 走势图展示区间累计收益率走势（%）、对应日期的单位净值与累计净值。
- 实现估值准确性对齐分析：将每日 15:00 收盘前的模型最终预估涨跌幅与官方确认的实际涨跌幅关联对比，输出偏离度（误差绝对值 MAE、方向吻合率等指标）。
- 走势曲线及数据点 Tooltip 支持叠加展示“官方实际涨跌”与“盘中预估涨跌”，直观呈现算法拟合度。
- 服务端增加高效的多级缓存机制，避免频繁请求上游外部接口导致反爬限流。

**Non-Goals:**
- 不在本地数据库中长期持久化存储数千只非自选基金的数十年历史日K/逐日净值大表；历史数据按需懒加载并由服务端 Caffeine 缓存驱动。
- 不提供复杂的量化多因子回测模型或基准对比归因系统。

## Decisions

### 1. 历史走势数据源选型
- **决策**：使用天天基金移动端 `FundNetDiagram.ashx` 官方标准接口（或品种数据 `pingzhongdata` 接口）。
- **理由**：该接口天生支持 `RANGE` 参数（`y`, `3y`, `6y`, `n`, `3n`, `5n`, `all`），直接输出标准的逐日净值、复权增长率及时间戳数组，数据精简、网络开销小。
- **备选方案**：爬取网页端历史净值表格分页 HTML。解析复杂、请求次数多、容易被风控，故放弃。

### 2. 预估涨跌幅与实际涨跌幅对齐策略
- **决策**：
  - 本地 `estimate_history` 表已持久化了每个交易日自选/监控基金的逐点估算记录。
  - 取每个交易日 `14:50 ~ 15:00` 之间的最后一条估算记录作为“当日最终预估值 (`est_pct`)”。
  - 与基金官方在当晚公布的最新实际涨跌幅 (`actual_pct`) 按日期进行联合对比。
  - 计算关键准确度指标：
    - 单日偏差：`diff_pct = est_pct - actual_pct`
    - 平均绝对误差 (MAE)：`sum(|diff_pct|) / N`
    - 方向吻合率 (Direction Match Rate)：`(同涨或同跌天数) / 总比对天数`
- **备选方案**：仅展示当天单日的预估偏差。不足以让用户建立对算法长期稳健性的信任，因此支持多日历史回溯对照。

### 3. 数据缓存与防限流策略
- **决策**：历史交易日数据具有“一旦确认即不再变动”的不可变性特性。在服务端采用 `Caffeine` 内存缓存，Cache Key 为 `fundCode + ":" + range`，针对历史区间设置 12 小时 TTL；仅当天盘中数据为动态更新。
- **收益**：相同基金的高频查看 99% 命中本地内存，零外部网络 I/O，彻底免疫反爬。

### 4. 前端图表交互设计 (ECharts)
- **决策**：
  - 在 `FundDetailPage.tsx` 现有分时图上方引入 Ant Design `Segmented` 控制器，提供“日内实时分时 / 历史业绩走势”视图切换；
  - 历史走势视图下提供 7 档快捷切换（近1月、近3月、近6月、近1年、近3年、近5年、成立以来）；
  - ECharts 折线采用平滑面积渐变曲线，在有本地估值对比记录的日期点上标注对比 MarkPoint 或在 Tooltip 中展示：
    `2026-11-20: 实际涨跌 +1.25% | 预估涨跌 +1.21% (偏离 -0.04%)`。

## Risks / Trade-offs

- **[Risk]** 针对刚加入自选的新基金，本地数据库无历史预估点位。
  - **Mitigation**: 界面友好提示“本地估值追踪始于 [起始日期]”，在此之前仅展示真实历史走势曲线，不展示空白误差。
- **[Risk]** 新成立不久的次新基金缺少 3 年或 5 年历史数据。
  - **Mitigation**: 前端根据返回的数据集时间跨度自动置灰不可用选项或自动平滑适配实际最大跨度。
- **[Risk]** 外部数据源偶发网络波动或防爬。
  - **Mitigation**: 沿用项目现有的 `RateLimiter` 与指数退避重试，并设置降级兜底提示。
