## Why

用户在查看单只自选基金时，当前详情页仅展示单日分时估值走势，无法直观了解基金在中长期历史维度（如近1月、近3月、近1年等）的净值增长表现与回撤走势。
同时，用户在使用盘中估值时，最关心的痛点是“算法预估到底准不准”。通过将盘中预估涨跌幅与收盘官方公布的实际涨跌幅进行同屏对照与误差分析，不仅能帮助用户全面把控基金业绩，还能直观建立对系统估值精度的信任度与预期判断。

## What Changes

- **历史业绩走势多周期切换**：
  - 支持 7 种主流时间范围筛选：近1月 (`1m`)、近3月 (`3m`)、近6月 (`6m`)、近1年 (`1y`)、近3年 (`3y`)、近5年 (`5y`)、成立以来 (`all`)。
  - 数据点包含历史净值（单位净值/累计净值）、区间累计收益率走势（%）。
- **预估涨幅值与准确性对照**：
  - 走势图上或对照面板中展示官方收盘真实涨跌幅与盘中模型预估涨跌幅的对比（如最新交易日及历史日期的预估涨跌幅 vs 官方确认涨跌幅）。
  - 提供预估准确性统计指标：包括预估偏离绝对值 (MAE)、涨跌方向预测准确率 (Direction Accuracy) 与拟合偏差区间。
- **后端历史净值与准确度分析接口**：
  - 新增拉取基金历史净值与收益率走势数据的 API (`/api/fund/{code}/performance?range={range}`)，集成多级缓存（Caffeine + 内存/数据源）保证高频访问性能。
  - 新增估值准确度对比接口或在详情/业绩中合并返回近期盘中最终估值 vs 官方收盘净值的对比数据点。
- **前端详情页 ECharts 走势图升级**：
  - 详情页支持“日内分时估值 / 历史业绩走势”双视图切换或标签页联动。
  - 历史走势曲线集成 Ant Design Segmented / Radio 切换近1月至成立以来 7 个维度，并支持 Hover Tooltip 同步展示净值、收益率与预估对比标签。

## Capabilities

### New Capabilities
- `fund-performance-history`: 基金历史业绩走势与净值走势数据采集、缓存与多周期接口（支持近1月、近3月、近6月、近1年、近3年、近5年、成立以来）。
- `valuation-accuracy-analysis`: 盘中最终估值涨跌幅与官方收盘实际净值涨跌幅对比，提供误差与准确度分析能力。

### Modified Capabilities
- `fund-detail-ui`: 基金详情页新增多周期历史业绩走势图切换（近1月至成立以来）及预估涨跌幅与真实涨跌幅对比展示。

## Impact

- **数据层/缓存**：引入天天基金历史净值数据接口解析，结合本地缓存机制减少外部反爬压力；复用 `estimate_history` 与 `fund` 表历史数据。
- **后端代码**：
  - `TianTianFundClient`: 增加历史业绩走势（NetDiagram）API 拉取。
  - `FundPerformanceService` / `PerformanceController`: 历史走势组装与准确度对比逻辑。
  - `FundController` / `FundDetailView`: 扩展详情接口返回准确度摘要或新增独立查询端点。
- **前端代码**：
  - `FundDetailPage.tsx`: 增加时间维度选择器与历史业绩折线图。
  - `frontend/src/api`: 新增历史业绩查询与准确度数据类型定义。
- **破坏性变更**：无破坏性变更（纯新增接口与扩展现有详情界面）。
