## Context

当前基金估值平台提供了基金详情、自选列表实时估值、持仓今日收益测算等高价值功能。然而作为纯网页应用，缺乏主动触达用户的管道，用户往往因工作繁忙忘记打开网页，导致平台客户粘性低、日活随行情波动大。

在中国场外基金交易规则下，**每个交易日 14:30-15:00 是关键黄金半小时**（按当天收盘净值确认份额，15:00 后则顺延至下一交易日）。用户在这个时段最迫切需要知道：“我的持仓今天大概赚了还是亏了？自选重点关注的基金涨势如何？要不要调仓或补仓？”。通过在 14:30 主动将用户定制的收益与走势推送到邮箱或个人微信，能直接击中用户痛点并建立不可替代的习惯依赖。

## Goals / Non-Goals

**Goals:**
- 提供用户维度的通知渠道绑定能力，零门槛支持电子邮箱与微信通知渠道（包括个人微信扫码绑定的 WxPusher、企业微信群机器人、钉钉、飞书、Server酱、Bark）。
- 每日交易日 14:30（收盘前半小时）自动识别开市状态，若开市则批量生成个性化组合估值简报并异步推送。
- 设计美观清晰的响应式 HTML 邮件模板与微信 Markdown 卡片模板，具备清晰的红绿盈亏视觉与回流网站快捷入口。
- 管理后台支持动态配置系统 SMTP 邮件服务参数（支持 163、QQ、阿里云企业邮等），无需重启服务即时生效。
- 提供一键通道测试功能，方便用户和管理员验证配置是否正确。

**Non-Goals:**
- 短信验证码或短信推送（短信成本高、无法呈现丰富的图文红绿表格与深层链接）。
- 原生 App APNs / FCM 系统推送（保持轻量级 Web 架构）。

## Decisions

### 1. 通知渠道选型与架构设计
- **邮箱渠道**：集成 `spring-boot-starter-mail`。在数据库 `sys_email_config` 中存储发件配置，运行时通过 `JavaMailSenderImpl` 动态构建发信实例，支持随时在管理后台变更 SMTP 授权码而无需重新打包镜像。
- **微信渠道**：考虑到个人开发者或普通站长通常没有已认证的微信服务号（微信模板消息需要企业认证与域名 ICP 备案），采用兼容性极佳的灵活架构：
  1. 支持标准 Webhook（用户可填写企业微信/钉钉/飞书群机器人 Webhook）；
  2. 支持个人微信推送神器 **WxPusher**（用户只需扫系统展示的二维码关注公众号，即可在微信即时接收消息）；
  3. 支持 iOS 用户喜爱的 **Bark** 与 **Server酱**。
- **用户渠道存储**：新增 `user_notification_channel` 表，绑定 `user_id`，独立存储各通道的启用开关与定制偏好。

### 2. 调度与交易日历联动
- 定时表达式：`@Scheduled(cron = "0 30 14 * * 1-5", zone = "Asia/Shanghai")`。
- 执行前首要校验：`TradingCalendar.isTradingDay(LocalDate.now())` 与 `calendarHolidayService.isHoliday(LocalDate.now())`。非交易日严格静默跳过，避免节假日打扰用户。
- 任务执行前触发一次估值刷新（Warmup），确保 14:30 推送的数据为最新行情。

### 3. 个性化内容聚合与模板引擎
- 针对每个开启提醒的用户：
  - 若用户是 VIP 且开启了持仓提醒：汇总持仓总市值、今日预估盈亏金额与收益率，并列出持仓基金中涨幅最高与跌幅最大的标的；
  - 若开启自选提醒：汇总全部自选基金当前预估净值与涨幅，按涨跌幅智能排序；
  - 隐私保护：提供「隐藏具体金额」开关，开启后仅展示百分比涨跌，不外露资产总额。
- 模板渲染：使用内置的高兼容性 HTML 邮件模板（对标 Morningstar / 蚂蚁财富日报风格，内联 CSS，手机端邮件客户端完美适配）。

## Risks / Trade-offs

- **[Risk] SMTP 邮件发送被服务商（如 QQ / 163）限流或拦截为垃圾邮件**
  → **Mitigation**: 
  1. 采用线程池异步发送，用户之间增加 100~300ms 动态发信微间隔；
  2. 邮件 Header 严格规范（设置标准的 Message-ID、Date、From 与 MIME-Version）；
  3. 提供多渠道选项（微信/Webhook 作为高可靠双保险）。
- **[Risk] 14:30 盘中行情接口波动或网络超时**
  → **Mitigation**: 
  若个别行情接口在 14:30 出现重试，降级使用上一分钟本地缓存的估值数据，标明行情时间戳，并在推送内容中标注「盘中估算数据仅供参考」。
- **[Risk] 邮件配置变更时的并发安全性**
  → **Mitigation**: 
  系统发件人对象使用 `AtomicReference<JavaMailSenderImpl>` 缓存，管理后台更新时原子替换。

## Migration Plan

1. 数据库自动迁移器 `DatabaseAutoMigrator` 补齐 `user_notification_channel` 和 `sys_email_config` 结构。
2. 后端引入 `spring-boot-starter-mail` 依赖与发信服务。
3. 前端导航栏与个人中心增设「每日提醒」配置模态框。
4. 全程向前兼容，原有自选与持仓功能不受任何影响。
