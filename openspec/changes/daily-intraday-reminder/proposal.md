## Why

网页端基金估值工具面临用户粘性低、使用频次低、依赖用户主动记忆与访问的普遍痛点。由于 A 股与场外基金的关键调仓/止盈止损决策窗口期正是交易日收盘前半小时（每日 14:30 左右），在此关键节点向用户提供高价值的即时收益估算，具有极强的用户刚需。

通过支持用户绑定电子邮箱或个人微信通知渠道，在每个交易日的 14:30 准时将用户量身定制的「持仓今日预估收益总览 + 自选基金盘中走势播报」自动推送到其邮箱或微信，既能使用户在繁忙工作时无需打开网页即可轻松掌握组合动态，又能在黄金交易时段建立强粘性连接，唤醒用户回流，显著提升留存与活跃度。

## What Changes

- **用户通知渠道绑定与偏好设置**：
  - 用户可在前台个人设置/自选页绑定通知渠道：电子邮箱（支持一键发送测试邮件）、微信通知渠道（支持免开发扫码绑定的 WxPusher 微信个人推送，及企业微信/钉钉/Server酱/Bark 等 Webhook）。
  - 支持自主配置 14:30 提醒开关、推送内容范围（仅推送持仓基金 / 推送全部自选基金）、是否包含敏感金额等个性化选项。
- **交易日 14:30 盘中定时调度与多通道推送引擎**：
  - 基于 Spring `@Scheduled` 与交易日历 `TradingCalendar`，非交易日与休市日自动跳过，交易日 14:30 准点触发。
  - 批量聚合已开启提醒用户的持仓预估数据与自选估值，分发至用户绑定的邮箱或微信通道。
  - 精心设计移动端友好的 HTML 邮件模板与微信 Markdown 卡片（清晰展示持仓收益、自选红绿涨跌、当日领涨领跌基金及一键直达网页的登录链接）。
- **管理员系统发信与推送配置**：
  - 在管理控制台新增 SMTP 发信配置（支持 163、QQ、阿里云、腾讯云企业邮箱等标准 SMTP 服务）。
  - 支持管理员手动触发 14:30 推送测试，并查看通道发送健康度与统计。

## Impact

- **新增依赖**：`spring-boot-starter-mail` (JavaMailSender 用于邮件发送)。
- **数据结构**：新增 `user_notification_channel` 表（存储用户渠道与偏好）以及 `sys_email_config` 表（存储系统发件配置）。
- **后端服务**：新增 `UserChannelService`、`DailyReminderScheduler`、`EmailSenderService`、`WxNotificationService`。
- **前端交互**：自选/持仓页新增「每日提醒」设置入口，用户可快速绑定邮箱或微信接收每日 14:30 盘中提醒。
