## Context

当前 BOND 策略对利率债部分按 0 涨跌近似,纯债基金(无股票/可转债持仓)盘中估值恒等于昨日净值,参考价值为零。Choice 等终端的"利率矩阵"展示了利率债收益率曲线(品种 × 期限 × 到期收益率),收益率变化是债券价格变动的主要驱动。本设计引入利率数据链路,让纯债基金估值"动起来"。

沿用已验证的数据源体系:行情走东财 push2(已支持多节点轮换),日更数据走公开网页抓取。

## Goals / Non-Goals

**Goals:**
- 纯债基金盘中估值不再恒等于昨日净值,输出"久期 × Δ收益率"驱动的估算涨跌幅
- 盘中使用国债期货主力合约(T/TF)作为利率方向实时代理,日更中债收益率曲线校准
- 与现有可转债实时行情共存:BOND 策略 = 可转债贡献 + 利率债贡献
- 数据缺失时优雅降级(按 0 近似 + 缺失标记)

**Non-Goals:**
- 逐券估值(对每只持仓债券精确估值)——参考级不需要
- 信用债利差模型(信用利差变化单独建模)——后续迭代
- 银行间实时行情接入(无公开来源)

## Decisions

### D1: 收益率变化的两段式估算——盘中代理 + 日更校准

```
盘中(每 2min): 国债期货主力涨跌幅 → 映射为 10Y/5Y 收益率变化(bp)
  Δ收益率 ≈ -期货涨跌幅% × 系数(如 10Y: 1bp ≈ 0.1%~0.15% 期货变动,按品种标定)

日更(每日): 中债收益率曲线(品种×期限) → 精确的当日 Δ收益率
  盘中估算: 昨日日更Δ + 期货盘中增量修正
```

**理由**: 银行间利率债无实时行情,国债期货是唯一可实时获得的利率代理;收益率曲线每天免费发布,提供精确基准。两段式在参考级精度下成本最低。

**备选**: 仅用期货代理(无日更校准)→ 系数标定不准确;仅用日更(无盘中)→ 盘中无变化。均否决。

### D2: 纯债估值模型——组合久期近似

```
利率债估算涨跌幅(%) = -组合久期(年) × Δ收益率(bp) / 100
```

- 组合久期来源优先级: 定期报告披露的久期 → 按基金类别默认(纯债 2.0,中短债 1.5,长债 4.0)
- 久期缺失时用配置默认值并标记"默认久期"
- 可转债持仓仍走实时行情,与利率债贡献叠加

**理由**: 债券价格对收益率的敏感度近似线性(久期近似),对参考级估值足够;无需逐券计算。

**备选**: 逐券剩余期限累加权 → 需要全量持仓+到期日,数据成本高,否决。

### D3: 数据模型——新增久期表

```
bond_duration  基金组合久期: fund_code+report_qt, duration(年), source(report/default)
```

久期随持仓报告期变更更新。收益率数据**不单独建表**:TY00Y 行情直接复用 `quote_cache`(secid=103.TY00Y)与内存缓存,新鲜度管理沿用现有机制。

### D4: 数据源

| 数据 | 来源 | 频率 |
|---|---|---|
| 10Y 国债收益率指数 | 东财 push2(`103.TY00Y`,已验证实时可用) | 盘中批量 |
| 中债收益率曲线 | 中国债券信息网(日更,可选) | 日更 |
| 组合久期 | 天天基金 F10(定期报告)或配置默认 | 报告期 |

**注(实现期决策,替代 D1 的期货代理方案)**: 实测发现东财 push2 直接提供 **`103.TY00Y`"10年期国债收益率"实时指标**(f3 涨跌幅实时可用),比"国债期货→收益率映射"更直接、误差更小。因此**放弃国债期货代理,直接使用该收益率指数作为利率驱动源**。模型:

```
利率债估算涨跌幅(%) = TY00Y涨跌幅(f3) × (组合久期 / 参考久期)
参考久期默认 10(10Y 国债组合久期近似值,可配置)
```

TY00Y 行情自动纳入现有 quote_cache 与批量行情链路,无需额外数据源客户端。chinabond 官网接口经实测返回空/405,**不作为依赖**,仅作可选增强。

### D5: 降级策略

- 期货行情缺失 → 用最近一次有效期货数据;仍缺失 → 利率债部分按 0,标记"利率数据缺失"
- 日更曲线缺失 → 保留最近交易日曲线,标记"收益率陈旧"
- 久期缺失 → 默认久期 + 标记"默认久期"

## Risks / Trade-offs

- **[期货代理系数不精确]** 期货涨跌幅到收益率 bp 的映射是近似 → 参考级可接受;日更曲线校准控制长期漂移。
- **[久期数据获取困难]** 定期报告久期披露不全 → 默认久期兜底 + 标记,用户可自行校正。
- **[中债网站抓取稳定性]** 官网页面结构可能变更 → 抓取解析集中封装,失败保留旧数据。
- **[收益率变动对信用债失效]** 模型仅覆盖利率风险,信用利差变动未建模 → 定位为利率债为主的估算,信用债占比较高的基金误差更大,明示局限。
