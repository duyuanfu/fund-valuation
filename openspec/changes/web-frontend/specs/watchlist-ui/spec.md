## ADDED Requirements

### Requirement: 自选估值列表渲染
系统 SHALL 展示当前用户的自选基金估值列表,包含估算净值、估算涨跌幅、净值日期、持仓报告期、行情时间、类型标识与免责声明。

#### Scenario: 列表加载
- **WHEN** 用户进入自选估值列表
- **THEN** 页面请求自选估值接口并渲染列表,估算涨跌幅用红涨绿跌着色(中国市场惯例)

#### Scenario: 估算状态展示
- **WHEN** 某只基金无净值基准或估值异常
- **THEN** 列表展示相应状态与提示信息(如"无净值基准,无法估算")

#### Scenario: 免责声明展示
- **WHEN** 列表渲染完成
- **THEN** 页面底部展示"估值仅供参考,不构成投资建议"的免责声明

### Requirement: SSE 实时更新
系统 SHALL 通过 SSE 接收后端推送的估值更新并就地更新列表,不整体刷新页面。

#### Scenario: 盘中推送更新
- **WHEN** 后端通过 SSE 推送新的估值列表
- **THEN** 页面就地更新对应基金的估值数据

#### Scenario: SSE 断线重连
- **WHEN** SSE 连接意外断开
- **THEN** 页面自动重连,并继续正常接收更新
