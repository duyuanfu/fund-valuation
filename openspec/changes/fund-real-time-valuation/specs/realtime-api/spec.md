## ADDED Requirements

### Requirement: REST 查询接口
系统 SHALL 通过 REST 接口提供自选基金估值列表、单只基金估值详情与持仓明细的查询。

#### Scenario: 查询自选基金估值列表
- **WHEN** 客户端 GET 请求自选估值列表接口并携带用户身份
- **THEN** 系统返回该用户全部自选基金的估值视图

#### Scenario: 查询单只基金详情
- **WHEN** 客户端 GET 请求单只基金详情接口
- **THEN** 系统返回该基金的基本信息、当前估值、持仓明细(含权重与报告期)及当日估值历史

### Requirement: SSE 实时推送
系统 SHALL 通过 SSE(Server-Sent Events)在盘中向在线用户推送其自选基金的最新估值更新。

#### Scenario: 盘中估值推送
- **WHEN** 盘中完成一轮估值计算,且用户在线的自选基金估值发生变化
- **THEN** 系统通过 SSE 向该用户推送更新后的估值数据

#### Scenario: 非交易时段无推送
- **WHEN** 处于非交易时段
- **THEN** 系统不通过 SSE 推送估值更新

### Requirement: 交易时段判定
系统 SHALL 判定当前是否处于 A 股交易时段(工作日 9:30-11:30、13:00-15:00),用于控制盘中估值计算、历史记录与 SSE 推送。

#### Scenario: 交易时段内执行盘中任务
- **WHEN** 当前处于 A 股交易时段
- **THEN** 系统执行盘中估值定时任务并允许 SSE 推送

#### Scenario: 非交易时段跳过盘中任务
- **WHEN** 当前处于非交易时段(包括午间休市)
- **THEN** 系统跳过盘中估值任务,不写入历史、不推送 SSE
