## Why

基金净值每天收盘后(约 20:00+)才由基金公司公布,交易时段内投资者无法感知自选基金的实时表现。需要一个服务,在盘中根据公开的季报持仓和实时行情,估算自选基金的当日净值走势,精度为"参考级"即可(天天基金同类估值页水平)。

## What Changes

全新项目,构建基金实时估值服务(Spring Boot 单体):

- **基金元数据采集**: 每日拉取基金列表、类型分类(指数/增强/主动/混合/债券)、昨日净值
- **持仓采集**: 每日拉取季报前十大重仓股及占净值比例、混合基金的资产配置(股票/债券/现金占比)
- **行情采集**: 盘中定时批量拉取重仓股/跟踪指数/可转债的实时价格与涨跌幅,拉平去重后单次批量请求,带限流退避
- **估值引擎**: 按基金类型分派模型——指数基金用跟踪指数涨跌幅;主动/混合用重仓股加权+残差近似;债券基金用可转债实时行情+利率债近似
- **多用户自选基金**: 用户维护自选基金列表,盘中定时计算并推送估值
- **估值历史**: 盘中估算值落库,单只基金详情页展示当日/近期走势曲线
- **实时推送**: SSE 向在线用户推送自选基金估值更新
- **查询 API**: REST 接口提供自选列表、单只基金估值与持仓明细

## Capabilities

### New Capabilities
- `fund-catalog`: 基金元数据管理——基金列表、类型分类、昨日净值、跟踪指数
- `fund-holdings`: 持仓数据管理——季报前十大重仓股与权重、资产配置比例
- `market-quotes`: 行情采集与缓存——批量拉取、去重、限流治理、新鲜度标记
- `valuation-engine`: 估值计算——按基金类型分派模型,输出估算净值与估算涨跌幅
- `user-watchlist`: 多用户自选基金管理
- `estimate-history`: 估值历史记录与查询
- `realtime-api`: REST 查询接口与 SSE 实时推送

### Modified Capabilities
- 无(全新项目,不存在既有规格)

## Impact

- **代码**: 全新 Spring Boot 项目,无现有代码受影响
- **技术栈**: Java 17+、Spring Boot 3.x、MySQL 8.x、SSE(Spring MVC)、HTTP 客户端、定时任务(Spring @Scheduled)、缓存(Caffeine)
- **外部数据源**: 东方财富 push2 行情接口(已验证可用)、天天基金 fundmobapi 接口(已验证可用,存在反爬限流,需限流治理)
- **部署**: 单机部署即可满足参考级需求
