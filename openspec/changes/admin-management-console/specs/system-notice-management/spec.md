## ADDED Requirements

### Requirement: 系统通用公告配置面板
系统 SHALL 提供系统公告的可视化管理界面，支持管理员配置公告内容、展示类型、启用状态与用户关闭权限。

#### Scenario: 查看当前公告配置
- **WHEN** 管理员打开公告管理页面
- **THEN** 表单回显当前系统的公告正文、类型 (`info` / `success` / `warning` / `error`)、是否启用及是否允许用户关闭

#### Scenario: 更新并发布新公告
- **WHEN** 管理员编辑公告表单内容并点击“保存发布”
- **THEN** 系统更新公告配置，前端自选列表顶部即时同步展示新公告，且若内容变更自动重置用户之前的关闭记忆

#### Scenario: 关闭自定义公告
- **WHEN** 管理员将“启用公告”开关切换为关闭并保存
- **THEN** 系统停用自定义公告，自选列表页面顶部自动回退为市场交易时段状态提示
